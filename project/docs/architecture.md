# AI shot 技术架构设计文档

> 文档版本：V1.0 | 编写日期：2026-06-09 | 项目状态：MVP / Demo 阶段

## 1. 项目概述

AI shot（Venaitry）是一个面向海外市场的 AI 短剧平台，核心能力是通过 AI 本地化管线将中文短剧快速本地化为多语言版本。

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 模块化 | 按业务领域拆分，每个模块独立开发、测试、部署 |
| 渐进演进 | MVP 阶段模块化单体，后期平滑演进为微服务 |
| AI 优先 | AI 本地化管线作为独立服务，不耦合业务逻辑 |
| 云原生 | 容器化部署，水平扩展，弹性伸缩 |
| 性能保障 | Go 处理高并发链路，Python 专注 AI 计算密集型任务 |

### 1.2 架构决策记录 (ADR)

| 编号 | 决策项 | 选择方案 | 理由 |
|------|--------|----------|------|
| ADR-001 | 后端主语言 | Go | 高并发、低延迟、编译型、部署简单 |
| ADR-002 | AI 管线语言 | Python | AI/ML 生态丰富 |
| ADR-003 | Web 前端 | Next.js | SSR 支持 SEO，React 生态成熟 |
| ADR-004 | 移动端 | Flutter | 跨平台一致性，视频播放体验好 |
| ADR-005 | 视频存储 | S3/R2 + CDN | 弹性扩展，按量付费 |
| ADR-006 | AI 策略 | 混合策略 | MVP 用第三方 API，后期逐步自建 |
| ADR-007 | 架构模式 | 领域模块化 | 兼顾 MVP 速度与后期演进能力 |

### 2.3 架构演进路线

| 阶段 | 架构形态 | 说明 |
|------|----------|------|

## 3. 模块详细设计

### 3.1 API 网关 (Go)

| 功能 | 说明 |
|------|------|
| 路由转发 | 根据请求路径转发到对应后端服务 |
| 身份认证 | 验证 JWT Token / OAuth 2.0 token |
| 速率限制 | 基于 IP / 用户维度的 Rate Limiting |
| 请求日志 | 全量请求日志记录 |
| 负载均衡 | 后端服务实例的流量分发 |
| CORS 管理 | 跨域访问策略控制 |
| 灰度发布 | 支持基于 Header/Cookie 的路由分流 |

### 3.2 用户与认证服务 (Go)

- 多账号体系：Google OAuth 2.0 / Apple Sign In / Facebook Login / 邮箱密码
- JWT 双令牌机制：Access Token (15min) + Refresh Token (30天)
- 密码加密：BCrypt（cost=12）
- 登录异常检测：异地登录检测、频繁失败锁定
- 用户资料管理：头像、昵称、偏好设置

### 3.3 内容服务 (Go)

| 子模块 | 说明 |
|--------|------|
| 短剧管理 | CRUD、分类、标签、上下架管理 |
| 推荐聚合 | 调用推荐引擎获取推荐列表，聚合元数据 |
| 收藏管理 | 收藏/取消收藏、列表查询、云同步 |
| 评论管理 | 发布、删除、点赞、回复、举报 |
| 搜索 | 对接 Elasticsearch，提供全文搜索 |

### 3.4 视频管理服务 (Go)

| 功能 | 说明 |
|------|------|
| 上传管理 | 分片上传、断点续传、MD5 校验 |
| 转码编排 | 提交转码任务到 FFmpeg 集群 |
| 存储管理 | 对接 S3/R2，生命周期管理 |
| CDN 分发 | 签名 URL 生成、防盗链 |
| 播放鉴权 | Referer 校验 + URL 过期签名 |

### 3.5 支付订阅服务 (Go)

- 支付渠道：Visa/Mastercard / PayPal / Apple Pay / Google Pay
- 订阅管理：月/季/年订阅，自动续费，过期处理
- 支付回调：Webhook 处理，幂等性保障
- 订单系统：支付订单生成、状态流转、退款
- 对账：每日支付对账，异常交易告警

### 3.6 BFF 层 (Node.js / Next.js)

| BFF 类型 | 职责 |
|----------|------|
| Web BFF | 服务端渲染 (SSR)、SEO 优化、页面数据聚合、路由管理 |
| App BFF | 移动端数据聚合、离线缓存策略、推送通知集成 |

### 3.7 管理后台服务 (Go / Next.js)

| 模块 | 说明 |
|------|------|
| 用户管理 | 用户列表、详情、封禁/解封、权限管理、登录日志 |
| 内容审核 | AI 自动审核 + 人工审核工作台 |
| 数据统计 | DAU/MAU、播放量、完播率、收入数据实时看板 |
| 系统配置 | 全局配置、公告管理、功能开关 |

## 5. 视频处理与分发

### 5.1 上传流程

```
用户/创作者 → 选择视频文件
    ├─ 客户端：MD5 计算 → 请求上传凭证
    ├─ Video Service：生成 Presigned URL（S3/R2）
    │   ├─ 文件 ≤ 100MB：直接 PUT 上传
    │   └─ 文件 > 100MB：分片上传 (S3 Multipart)
    ├─ 上传完成 → 回调通知 Video Service
    ├─ 视频校验：格式 / 分辨率 / 时长 / 文件大小
    ├─ 提交转码任务 + AI 本地化任务
    └─ 返回上传结果 + 处理状态
```

### 5.2 转码策略

| 清晰度 | 分辨率 | 码率 | 格式 |
|--------|--------|------|------|
| 1080P | 1920×1080 | 4-6 Mbps | H.264 MP4 |
| 720P | 1280×720 | 2-3 Mbps | H.264 MP4 |
| 480P | 854×480 | 1-1.5 Mbps | H.264 MP4 |
| 音频 | - | 128 Kbps | AAC / MP3 |

### 5.3 CDN 分发策略

- CDN：Cloudflare Stream（全球加速）
- 缓存策略：热门内容边缘缓存，长尾内容回源
- 防盗链：Referer 校验 + URL 过期签名（有效期 1 小时）
- 自适应码率：HLS 多码率输出
- 预热机制：新热门剧集上线时主动 CDN 预热

## 6. 安全架构

### 6.1 多层安全防护

| 层级 | 防护措施 |
|------|----------|
| 网络层 | HTTPS/TLS 1.3、WAF、DDoS 防护（Cloudflare） |
| 接入层 | API Rate Limit、IP 黑白名单、请求签名验证 |
| 认证层 | JWT 双 Token、OAuth 2.0、BCrypt 密码加密 |
| 应用层 | SQL 注入防护 (ORM)、XSS 过滤、CSRF Token |
| 数据层 | 数据加密存储、敏感字段脱敏、访问审计日志 |
| 内容层 | AI 自动审核 + 人工复审、版权保护机制 |

### 6.2 认证与授权

采用 JWT + OAuth 2.0 混合认证方案：
- Access Token：短期有效（15min），携带用户身份和角色
- Refresh Token：长期有效（30天），用于刷新 Access Token
- OAuth 2.0：Google/Apple/Facebook 第三方登录
- RBAC 权限模型：用户/创作者/管理员/超级管理员四级角色

## 7. 性能架构

### 7.1 性能目标

| 指标 | 目标 |
|------|------|
| API 平均响应时间 | < 200ms (P95) |
| API 峰值吞吐 | 5,000 QPS |
| 同时在线用户 | 10,000+ |
| 视频首帧加载 | < 3s |
| 播放成功率 | ≥ 99% |
| 系统可用性 | 99.9% |

### 7.2 缓存策略

| 缓存层 | 技术 | 策略 |
|--------|------|------|
| 浏览器缓存 | Cache-Control Header | 文件哈希 + 长期缓存 |
| CDN 缓存 | Cloudflare | 热门 7天，长尾 1天 |
| 应用缓存 | Redis | LRU + TTL 过期 |
| 数据库缓存 | PostgreSQL Buffer Pool | 配置合适的 shared_buffers |

### 7.3 扩容策略

| 场景 | 触发条件 | 扩容动作 |
|------|----------|----------|
| CPU 飙升 | CPU > 70% | 增加 Pod 副本数 |
| 内存压力 | 内存 > 80% | 增加 Pod 副本数 / 提升实例规格 |
| QPS 增长 | QPS > 3000 | 水平扩展 API 服务 |
| 视频请求激增 | 带宽 > 5 Gbps | CDN 扩容 + 回源扩容 |
| 数据库压力 | 连接数 > 80% | 增加只读副本 |
